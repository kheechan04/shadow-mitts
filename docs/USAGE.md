# 사용법

## 준비물

- **웹캠**이 있는 PC/노트북, **Chrome** (또는 Edge) 최신 버전
- 카메라에서 **1.5~2m** 떨어져 설 수 있는 공간. 팔을 뻗어도 아무것도 닿지 않게 주변을 비워 주세요.
- **리액션 얼굴(선택)**: 카메라를 켠 뒤 메뉴의 "😆 리액션 얼굴 → 📸 내 얼굴 찍기" (안 찍고 시작하면 한 번 물어봐요). 정면을 보고 있으면 표정 5개가 만들어지고,
  게임 중 오른쪽 위 창에서 판정마다 내 얼굴이 웃고 울어요(10콤보마다 CRITICAL). 사진은 이 기기 밖으로 안 나가고 저장하지 않아요
  ("지우기"나 창 닫기로 사라짐). 자세한 내용: docs/FACE-PRIVACY.md
- 결과 화면의 "이번 판 기록 저장"은 그 판의 동작(관절 좌표)과 판정 기록을 파일로 저장합니다. 영상은 저장하지 않아요.
- 밝은 조명. 어두우면 웹캠이 스스로 초당 15장으로 떨어지고 인식이 나빠집니다.
  카메라 창에 "인식 느림 (N fps)"이 뜨면 방을 더 밝게 해 주세요.

> 카메라는 브라우저 정책상 **HTTPS 또는 localhost**에서만 켜집니다. 영상은 브라우저 밖으로 나가지 않습니다.

## 설치형 앱으로 쓰기 (PWA)

배포 주소 **https://shadow-mitts.vercel.app** 을 크롬·엣지로 열면 주소창 오른쪽에 **설치** 아이콘(또는 메뉴 → "앱 설치")이 보여요.
설치하면 바탕화면·작업표시줄 아이콘으로 **주소창 없는 앱 창**에서 열리고, 한 번 받은 게임·모델 파일을 저장해 두어
다음부터 빨리 켜지며 인터넷이 끊겨도 실행돼요. 저장되는 건 게임 파일뿐(사진·영상·얼굴 아님). 앱 창에서 "제거"로 지울 수 있어요.
(개발 서버 `npm run dev`에서는 이 기능이 꺼져 있어요.)

## 실행 (개발용)

```bash
npm install
npm run dev
```

Chrome에서 **http://localhost:5173** 을 엽니다.

Windows PowerShell에서 `npm : 이 시스템에서 스크립트를 실행할 수 없으므로…` 오류가 나면 `npm.cmd run dev`로 실행하세요.
(또는 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` 한 번 실행)

## 플레이 순서

1. **카메라 켜기** — 카메라 목록에서 실제 웹캠을 고르고 "켜기". 카메라 화면 아래에 `준비 완료 ✓`가 뜨면 OK.
   `상체가 다 보이게 조금 뒤로`가 뜨면 한 걸음 물러나세요.
2. **스탠스** — 왼손이 앞이면 오소독스, 오른손이 앞이면 사우스포.
3. **난이도** — 🐣 쉬움(1~4번, 느긋하게) / 🥊 보통(1~6번, 3연타까지) / 🔥 어려움(빠르게, 4연타까지). 라운드 수와 시간도 고릅니다.
4. **자동 보정 (처음 한 번)** — 미트가 목표 링에 겹칠 때(삐 소리) 아무 손으로 잽을 8번. 카메라·인식 지연이 자동으로 맞춰집니다.
5. **▶ 한 판 붙자!**

게임 중 `Esc` 또는 왼쪽 아래 **그만**으로 끝낼 수 있습니다.

## 펀치 번호

| 번호 | 펀치 | 오소독스 | 사우스포 | 미트가 오는 모습 |
|---|---|---|---|---|
| 1 | 잽 | 왼손 | 오른손 | 앞손 쪽에서 정면을 보고 옴 |
| 2 | 크로스 | 오른손 | 왼손 | 정중앙, 몸이 도는 방향으로 틀어짐 |
| 3 | 리드 훅 | 왼손 | 오른손 | 옆에서 휘어 들어와 거의 90° 틀어짐 |
| 4 | 리어 훅 | 오른손 | 왼손 | 반대쪽 옆에서, 거의 90° |
| 5 | 리드 어퍼컷 | 왼손 | 오른손 | 아래에서 올라와 아래를 향함 |
| 6 | 리어 어퍼컷 | 오른손 | 왼손 | 반대쪽 아래에서 |

미트와 화면 위 콤보 칩의 **색**이 쓸 손을 알려 줍니다 (하늘색 = 왼손, 주황 = 오른손).

## 판정

- 미트가 날아와 **자리에 멈춘 뒤 잠깐 대 주고 있습니다.** 미트 둘레 게이지가 남은 시간이에요.
- 그동안 **맞는 손으로 맞는 펀치**를 치면 맞음. 도착 무렵(게이지가 금색일 때)은 **PERFECT**, 그 뒤는 **GOOD**.
- 보통 난이도 기준 인식 구간: 도착 0.25초 전 ~ 0.75초 후.
- 펀치를 **어디에** 치는지는 보지 않습니다. 어느 손 · 어떤 펀치 · 언제만 봅니다. 자연스럽게 치세요.
- **반대 손 펀치는 감점하지 않습니다.**
- "종류 틀려도 부분 점수"를 켜면, 손은 맞고 펀치 종류만 다를 때 부분 점수(OK)를 받습니다.

**점수** — PERFECT 100 · GOOD 60 · OK 30. 10연속 성공마다 배율 +0.1(최대 ×2).
치지 않는 손이 턱 근처(가드)에 있으면 +20%. 화면 아래 가드 표시를 확인하세요.

**인식 요령 — 크고 또렷하게!**
- 펀치는 **크고 또렷하게** 치세요. 작게 톡 치면 웹캠 프레임 사이에 동작이 묻혀 놓칠 수 있어요(특히 30fps 이하 카메라).

- **직선(잽·크로스)**: 카메라 쪽으로 곧게 뻗기
- **훅**: 팔꿈치를 들어 팔뚝이 옆으로 눕게 휘두르기
- **어퍼컷**: 살짝 내렸다가 팔꿈치를 낮게 두고 위로 올려 치기

**타격감 설정** — 메뉴에서 **소리**와 **흔들림·번쩍임**을 끌 수 있습니다(멀미가 나거나 빛에 민감하면 흔들림·번쩍임을 끄세요).

## 결과 화면

등급(S~D), 점수, 최대 콤보, 정확도, 펀치별 명중률이 나오고, 이번 판에 눈에 띄게 약한 펀치와 **누적 약점**을 알려 줍니다.

- **약점 집중**(메뉴, 기본 켜짐): 펀치별 정확도를 기억해서 약한 펀치를 다음 판부터 더 자주 냅니다(최대 3배).
- **내 기록**: 난이도별 최고 점수와 판 수가 메뉴에 나오고, 새 최고 기록이면 결과 화면에 🏆가 떠요.
  이 브라우저에만 저장되고(점수·펀치별 명중 수만, 영상·얼굴은 저장 안 함), 결과 화면의 "내 기록 지우기"로 지울 수 있어요.
  저장이 막힌 브라우저에서도 게임은 그대로 돼요.
- **결과 카드 저장**: 등급·점수·펀치별 막대가 들어간 1080×1350 PNG를 내 기기에 내려받아요.
  리액션 얼굴을 찍었다면 "카드에 내 얼굴" 스위치로 넣거나 뺄 수 있어요. 파일은 업로드되지 않아요.

## 개발자 도구 (⚙)

오른쪽 위 ⚙ 버튼. 게임을 즐기는 데는 필요 없습니다.

- **상태** — 검출 FPS, 추론 시간, 지연. FPS가 40 아래면 경고가 뜹니다(웹캠 대부분은 30fps가 정상).
- **펀치 인식 테스트** — 펀치를 치면 번호별 카운트와 기록이 쌓입니다. 인식이 잘 되는지 확인할 때 씁니다.
- **녹화/재생** — 관절 좌표를 JSON으로 저장하고 카메라 없이 다시 재생합니다. 메모 규칙은 [../recordings/README.md](../recordings/README.md).
- **튜닝** — 모든 인식 임계값 슬라이더. 바꾼 값은 브라우저에 저장되고, "기본값으로"로 되돌립니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| `AbortError: Timeout starting video source` | 가상 카메라(화상회의·시선추적 프로그램이 설치하는 것)가 기본으로 잡힌 경우가 많습니다. 카메라 목록에서 실제 웹캠을 고르세요. 화상회의 앱이 카메라를 쓰고 있으면 종료하세요. |
| `NotAllowedError` | 주소창 왼쪽 아이콘에서 카메라 권한을 "허용"으로 바꾸고 새로고침. |
| 펀치를 자주 놓침 | 조명을 밝게, 한 걸음 뒤로(상체 전체가 보이게), 개발자 도구에서 FPS 확인. 그래도 놓치면 튜닝의 "최소 최고 속도"를 낮춰 보세요(대신 잘못 잡히는 경우가 늘 수 있음). |
| 판정이 항상 빠름/늦음 | 화면 아래 타이밍 막대의 점이 한쪽으로 몰리면 "자동 보정"을 다시 하거나 타이밍 슬라이더를 조정하세요. |
| 어퍼컷이 직선으로 잡힘 | 살짝 내렸다가 올려 치기(딥). 또는 튜닝의 "어퍼컷 쪽으로 기울이기"를 올리세요. |
