# M6 계획 — 디펜스 (슬립 · 더킹 → 위빙)

작성: 2026-09-24 (M5 배포 직후). 사용자와 합의한 방향: **M5 먼저, M6는 새 마일스톤**, 첫 범위는 **슬립(좌/우)과 더킹**, 위빙은 그 조합이라 나중.
DESIGN.md에서 "대전 모드는 슬립/더킹 판정이 필요해 첫 버전 제외"로 미뤄 둔 부분이다.

## 왜 할 만한가 (사용자에게 설명한 내용)
- 실제 미트 훈련은 미트 잡이가 머리를 향해 휘두르면 피하고 다시 치는 공방이다 → "1-2 → 슬립 → 2" 같은 콤보가 게임의 차별점이 된다.
- 펀치는 카메라 쪽으로 뻗어 화면상 움직임이 작았지만, 디펜스는 **머리가 화면에서 크게 움직인다**(옆으로 / 아래로) — 인식이 오히려 쉬울 가능성.
- 위험: 크로스·훅을 칠 때도 몸이 돌며 머리가 옆으로 움직인다 → 슬립과 헷갈릴 수 있다. **녹화로 먼저 확인할 것.** 깊게 더킹하면 상체가 화면 밖으로 나갈 수 있다(거리 안내 중요).

## 1단계: 녹화 요청 (사용자에게 부탁할 것 — 먼저 이것부터)
개발자 도구(⚙) → 녹화. 메모는 아래 형식 그대로(나중에 `npm run eval`이 메모에서 정답을 읽는다). 한 동작 10회, 사이에 1\~2초 가드로 돌아오기.
LG Camera, 밝은 곳, 1.5\~2m 거리, 평소 게임하던 자세로.

| 메모 | 목적 |
|---|---|
| `사우스포, 슬립 왼쪽 10회` | 슬립 (머리를 왼쪽으로) |
| `사우스포, 슬립 오른쪽 10회` | 슬립 (머리를 오른쪽으로) |
| `사우스포, 더킹 10회` | 더킹 (무릎을 굽혀 머리를 아래로) |
| `사우스포, 콤보 1-2 슬립 5회` | 펀치 직후 슬립 — 실제 게임 흐름 |
| `사우스포, 제자리 스텝 10초` | 오검출 확인용 (발만 움직임) |
| (선택) `사우스포, 위빙 왼쪽 10회` / `위빙 오른쪽 10회` | 2단계용 |

"왼쪽/오른쪽"은 **사용자 몸 기준**으로 할지 **화면 기준**으로 할지 녹화 전에 사용자와 정하고 여기에 적을 것(좌표는 반전 전 이미지 기준으로 저장됨 — `docs/DEVELOPMENT.md` §3).
기존 녹화의 크로스·훅·가드·몸통 회전 구간은 **오검출 확인용 음성 데이터**로 그대로 쓴다.

## 2단계: 인식기 (카메라 없이, 녹화로)
- 새 순수 모듈 `src/core/defense.ts` + 단위 테스트, 임계값은 `params.ts`(placeholder, 슬라이더). `evaluate.ts`의 메모 파서에 "슬립 왼쪽/오른쪽", "더킹", "위빙" 추가.
- 후보 특징(녹화로 비교해서 고를 것 — 먼저 궤적을 그려 볼 것):
  - 머리 위치(코·입 중점·눈) — 기준점: ① 가드 때의 머리 위치 이동평균(펀치 가드 기준처럼) ② 엉덩이 중점 기준(몸 전체 이동 제거) ③ 어깨 중점 기준(어깨도 같이 기울어서 약할 수 있음). 단위는 몸통 길이 T.
  - 슬립 = 옆 이동이 크고 빠름, 세로는 작음 / 더킹 = 세로로 크게 내려감(어깨·머리 함께) / 위빙 = 내려갔다 옆으로 올라오는 U자.
  - 펀치와 구분: 같은 시각에 펀치 이벤트가 있는지, 양손이 가드 근처에 남아 있는지, 머리 이동 크기·속도.
- 목표(초안): 디펜스 녹화 10회 중 9회 이상, 기존 펀치·가드·몸통 회전 녹화에서 디펜스 오검출 0, 기존 펀치 인식 floor 유지. 15fps로 솎아도(`npm run fps-check`) 버티는지.

## 3단계: 게임 연결 (사용자 확인 후)
- "피하는 미트": 미트가 **얼굴을 향해** 날아오고 도착 순간 머리가 그 길에서 벗어나 있으면 성공(옆에서 휘두르면 더킹, 정면이면 슬립 방향 표시). 판정은 펀치처럼 도착 전후 창.
- `core/game.ts`: 디펜스 번호/종류 추가, 콤보 생성기에 공방 섞기(난이도별), 점수·콤보 연동. 적응형 출제·결과 통계에 디펜스 포함.
- 화면: 경고 표시(얼굴로 날아오는 미트), 성공 시 "휙" 연출, 리액션 얼굴 연동. 처음 방문 체크리스트/튜토리얼에 디펜스 설명.
- 미트 표시 규칙은 지금 규칙을 따른다: 시계대로만 움직이고, 판정된 건 제자리에서 사라지고, 되살아나지 않게(`scripts/dev/mitt-trace.mjs`로 확인).

## 사용자에게 먼저 물어볼 것
1. 녹화 방향 기준(몸 기준 vs 화면 기준).

3. 첫 난이도부터 디펜스를 섞을지, "공방 모드"를 따로 둘지.
