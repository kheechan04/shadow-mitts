# recordings/

개발자 도구(⚙) → **녹화/재생**으로 저장한 관절 좌표 JSON을 두는 곳입니다.
개인 동작 데이터라 **저장소에는 포함하지 않습니다** (`.gitignore`로 제외). 파일이 없으면 녹화 기반 테스트는 자동으로 건너뜁니다.

## 형식 (v1)

```jsonc
{
  "meta": { "version": 1, "createdAt": "...", "note": "사우스포, 리드 잽 10회",
            "aspect": 1.333, "videoWidth": 640, "videoHeight": 480, "model": "lite", "delegate": "GPU" },
  "frames": [
    { "t": 0,      // ms, 첫 프레임 = 0
      "lm": [[x, y, z, visibility], ...33],   // 정규화 이미지 좌표 (거울 반전 전), 사람이 없으면 null
      "wl": [[x, y, z, visibility], ...33] }  // 월드 좌표(m)
  ]
}
```

## 메모(note) 규칙 — 자동 채점용

`npm run eval`과 녹화 회귀 테스트는 메모를 읽어 정답을 압니다.

| 메모 예 | 의미 |
|---|---|
| `사우스포, 리드 잽 10회` | 1번 10회 (잽·크로스·리드/리어 훅·리드/리어 어퍼컷) |
| `오소독스, 리어 어퍼컷 10회` | 6번 10회 |
| `사우스포, 콤보 1-1-2 5회` | 1번 10회 + 2번 5회 |
| `사우스포, 가드 10초` / `사우스포, 몸통 회전 10초` | 펀치 없음 (잡히면 오검출) |
| `사우스포, 섞어서 자유롭게` | 채점 제외 |

스탠스(오소독스/사우스포)는 반드시 적어 주세요. `--mirror` 옵션은 좌우를 뒤집어 반대 스탠스 데이터로도 채점합니다.
